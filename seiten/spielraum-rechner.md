# Spielraum Rechner

Ziel: kurzer Input -> klares Ergebnis (Self-Serve).

## Inputs

- Netto
- Fixkosten
- Variabel (Plan)

## Outputs

- Spielraum pro Monat

## Hinweise

- Self-Serve, keine individuelle Einzelfallpruefung
- Wenn negativ: Fixkosten senken oder Einnahmen erhoehen
