# Schuldenfrei mit der Schneeball-Methode
Die Schneeball-Methode ist ein einfacher, motivierender Weg, Schulden planbar abzubauen: Du zahlst zuerst die kleinste Schuld komplett ab, dann rollst du die frei gewordene Rate zur naechsten Schuld weiter.
## So funktioniert es (kurz und klar)
1. Liste alle Schulden (Restbetrag, Zins, Mindestrate).
2. Zahle auf **alle** Schulden die Mindestzahlung.
3. Den Rest deines Monatsbudgets fuer Schulden zahlst du **zusaetzlich** auf die kleinste Schuld.
4. Wenn eine Schuld weg ist, addierst du deren Rate zur naechsten Schuld.
## Was du hier bekommst
* Ein schneller Rechner, der dir den Ablauf strukturiert
* Ein Download-Hub (Freebie / Vollversion-Links, sobald du es verlinkst)
* Ein klarer Naechster-Schritt-Flow ohne Sackgassen
