# Finanzen / Nachweise (Hinweis)

Aus Datenschutzgründen liegen **Finanz- und Nachweisunterlagen** (z. B. Auszahlungen, Reports, Jobcenter/Finanzamt-Kommunikation) **nicht im öffentlichen Repo**.

Die operative Checkliste sowie alle Belege werden **nur in privater Ablage** geführt.

**Regel:** Keine Kontoauszüge, Auszahlungsbelege, Reports, personenbezogene Daten, Summen oder Behördenkommunikation ins Repo committen.

**Arbeitsstandard:** Änderungen im Repo erfolgen **immer als kompletter Full-Swap** (vollständiger Dateiinhalt, kein Stückwerk).
