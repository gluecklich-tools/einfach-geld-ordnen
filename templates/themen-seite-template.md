# Themen-Seite Template (EGO)
Zweck: Vorlage fuer eine Themen-Seite (SEO + Self-Serve), ohne Supportversprechen.
## 1) H1 + Kurzpitch
- H1: [Keyword + Nutzen]
- 2-3 Saetze: fuer wen, welches Problem, welches Ergebnis
## 2) Quick Start (3 Schritte)
1) Schritt 1 (2-3 Minuten)
2) Schritt 2
3) Schritt 3
## 3) Kerninhalt (klar, kurz, umsetzbar)
- Abschnitt A (Definition / Beispiel)
- Abschnitt B (Checkliste)
- Abschnitt C (Haeufige Fehler vermeiden)
## 4) Mini-FAQ (Self-Serve)
- Frage 1: kurze Antwort
- Frage 2
- Frage 3
- Frage 4
- Frage 5
## 5) CTA (ohne Druck)
- Freebie: [was genau bekommt man]
- Vollversion: [was ist mehr drin]
- Hinweis: Keine Beratung, self-serve
## 6) Interlink-Plan (keine Sackgassen)
- Hub: [Uebersichtsseite]
- Rechner: [passender Rechner]
- 2 verwandte Themen-Seiten
