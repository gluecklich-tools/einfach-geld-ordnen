# Finanzen / Nachweise (Hinweis)

Aus Datenschutzgruenden liegen **Finanz- und Nachweisunterlagen** (z. B. Auszahlungen, Reports, Jobcenter/Finanzamt-Kommunikation) **nicht im oeffentlichen Repo**.

Die operative Checkliste sowie alle Belege werden **nur in privater Ablage** gefuehrt.

**Regel:** Keine Kontoauszuege, Auszahlungsbelege, Reports, personenbezogene Daten, Summen oder Behoerdenkommunikation ins Repo committen.

**Arbeitsstandard:** aenderungen im Repo erfolgen **immer als kompletter Full-Swap** (vollstaendiger Dateiinhalt, kein Stueckwerk).
