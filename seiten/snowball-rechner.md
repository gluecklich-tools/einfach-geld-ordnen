# Snowball Rechner

Ziel: Aus Schuldenliste + Extra-Budget eine einfache Reihenfolge ableiten (Self-Serve).

## Inputs
- Schulden (Name, Rest, Rate, Zins)
- Extra-Budget pro Monat

## Outputs
- Reihenfolge (Snowball)
- Naechster Fokus

## Hinweise
- Grobe Naeherung (kein Finanz-/Steuer-/Rechtsrat)
- Rundungen sind ok
