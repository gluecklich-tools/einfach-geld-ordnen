# Repo Completion Order Policy

## Status
Verpflichtend.

## Harte Reihenfolge bei Repo-Strängen

1. Repriorisieren
2. Repair / Apply
3. Verify / echte Prüfung
4. Commit / Push
5. Closeout / Status / Learnings / Spiegel
6. Resume / Themenwechsel

## Verboten

- Themenwechsel mit offenem Repo-P0
- "fertig" ohne echte Verifikation
- Wechsel in Produkt-/Claude-/anderen Strang ohne sauberen Repo-Abschluss
- Closeout vergessen
- Push/Commit als optional behandeln

## Operative Regel

Ein Repo-Strang gilt erst dann als abgeschlossen, wenn:
- offene P0s behoben sind
- Verifikation gelaufen ist
- Commit/Push erfolgt oder explizit blockiert und dokumentiert ist
- Closeout geschrieben ist
- Brain / _INTERN / Learnings systemisch aktualisiert sind

## Folge

Ohne diese Kette gibt es keinen sauberen Resume-Punkt.
