# Excel Claude Resume Protocol

## Resume-Regel

Vor dem nächsten Excel-/Claude-Lauf gilt:

1. Required Reads mit passendem TaskType ausführen
2. ZIP + Claude-Text als reale Arbeitsgrundlage verwenden
3. echten Datei-Zustand prüfen, nicht Claude-Behauptung
4. nur ein Blatt / ein Engpass pro Lauf
5. erst Freigabe, dann nächste Seite
