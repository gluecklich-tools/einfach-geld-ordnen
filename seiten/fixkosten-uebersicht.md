# Fixkosten übersichtlich erfassen

Fixkosten sind alle regelmäßig wiederkehrenden Ausgaben.

## Beispiele
- Miete (Kalt + Nebenkosten)
- Strom/Heizung
- Internet/Handy
- Versicherungen
- Abos/Verträge

## So ordnest du sie
- Liste **alle** Fixkosten auf
- schreibe den **monatlichen** Betrag dazu (Jahresbetrag ÷ 12)
- prüfe: *Welche kann ich kündigen oder senken?*

Nächster Schritt: variable Ausgaben.
