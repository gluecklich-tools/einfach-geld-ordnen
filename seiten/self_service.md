# 100% Self-Serve

Self-Serve-Produkt: eigenständig nutzbar, ohne zugesicherte Rückmeldung oder individülle Einzelfallprüfung.

## So funktioniert es

###
1. **Wichtig**: Start in 15 Minuten
- LibreOffice installieren/öffnen
- Datei laden und speichern (eigene Kopie)
- 3 Pflichtschritte: Kategorien -> Monat -> 1-3 Beispielbuchungen
- Mini-Check: Summe / Kategorie / Monat

###
2. **Wichtig**: FAQ / Probleme lösen (Top
15. - Dropdown geht nicht
- Formel kaputt / Werte falsch
- Monatswechsel
- Datei überschrieben / wiederherstellen
- Komma/Punkt / Währung / Format
- Handy/Tablet (nicht empfohlen)
- Versionierung / neü Version laden
- Druck/PDF etc.

###
3. Plattform regelt alles Organisatorische (kein eigener Kanal)
- Zahlung, Rechnung, Downloadzustellung, Widerruf/Refund: ausschliesslich über die Plattform
- Kein separater Kontakt für Abwicklung
- Keine Fragen per Mail/DM (weder inhaltlich noch technisch)

###
4. Erwartungsmanagement (Rückfragen verhindern)
- Für wen geeignet / für wen nicht
- Keine Einrichtung, kein Begleitung, keine individülle Unterstützung
- Wenn du mehr Unterstützung brauchst, ist dieses Angebot vermutlich nicht passend.
