# Jahreskosten-Kalender (damit dich grosse Rechnungen nicht ueberraschen)
Viele Kosten kommen nicht monatlich, sondern 1x pro Jahr oder quartalsweise (Versicherung, GEZ, Kfz, Mitgliedschaften).
Wenn du sie **vorher aufteilst**, wird dein Monat stabil.
## Mini-Plan (15 Minuten)
1. Sammle alle nicht-monatlichen Kosten (Kontoauszug, Vertrage, E-Mails).
2. Notiere: Betrag + wann faellig (Monat) + Rhythmus (jaehrlich / halbjaehrlich / quartalsweise).
3. Rechne jede Position auf **pro Monat** um.
4. Lege den Monatsbetrag auf ein separates Konto/Unterkonto zur Seite.
5. Wenn eine Rechnung kommt: bezahlen, danach weiter wie vorher (kein Stress).
## Typische Jahreskosten
* Kfz-Versicherung / Steuer
* Haftpflicht / Hausrat / Rechtsschutz
* GEZ (Beitrag)
* Mitgliedschaften (Verein, Fitness, Apps)
* Wartung/Inspektion, Schornsteinfeger, Fuehrerscheine/Fees
