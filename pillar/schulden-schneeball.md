# Schulden-Schneeball - Anleitung

Du tilgst zürst die kleinste Schuld. Das bringt schnelle Erfolge.

## Schritte
1. Sortiere Schulden nach Restbetrag (klein nach groß)
2. Minimum auf alle
3. Extra-Geld komplett auf die kleinste
4. **Nach Tilgung**: Extra auf die nächste
