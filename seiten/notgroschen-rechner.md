# Notgroschen Rechner

Ziel: Aus Monatsausgaben + Risiko-Level einen Zielbereich ableiten (Self-Serve).

## Inputs
- Monatliche Fixkosten
- Monatliche variable Ausgaben
- Risiko-Level (niedrig/mittel/hoch)

## Outputs
- Zielbereich Notgroschen
- Monatliche Sparrate (optional)
