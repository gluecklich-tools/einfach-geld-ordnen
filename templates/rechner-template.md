# Rechner Template (EGO)
Zweck: Statischer JS-Mini-Rechner als Self-Serve, klarer Input -> Output.
## 1) Ziel (1 Satz)
- Was berechnet der Rechner und fuer wen?
## 2) Inputs (max 3-6)
- Input 1: Name, Einheit, gueltiger Bereich
- Input 2
- Input 3
## 3) Output (max 1-3 Kennzahlen)
- Output 1: Erklaerung in 1 Satz
- Output 2 (optional)
- Output 3 (optional)
## 4) Regeln / Formel (pseudo)
- Formel / Logik in klaren Stichpunkten
## 5) Hinweise (Self-Serve)
- Rundungen
- typische Fehler
- Disclaimer (keine Beratung)
## 6) Interlink-Plan (keine Sackgassen)
- Hub: [Uebersicht]
- passende Themen-Seite
- verwandter Rechner
