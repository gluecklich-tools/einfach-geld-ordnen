# Spielraum Rechner

Ziel: kurzer Input -> klares Ergebnis (Self-Serve).

## Inputs

- Netto\n- Fixkosten\n- Variabel (Plan)

## Outputs

- Spielraum pro Monat

## Hinweise

- Self-Serve, keine Beratung\n- Wenn negativ: Fixkosten senken oder Einnahmen erhoehen
