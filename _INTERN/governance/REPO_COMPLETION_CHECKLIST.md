# Repo Completion Checklist

## Vor Themenwechsel
- [ ] Priorität neu bewertet
- [ ] Offene Repo-P0s geschlossen
- [ ] Verify real gelaufen
- [ ] Commit erfolgt
- [ ] Push erfolgt
- [ ] Closeout geschrieben
- [ ] Brain / _INTERN / Learnings aktualisiert
- [ ] Resume-Punkt dokumentiert

## Stop-Regel
Wenn ein Punkt offen ist:
Kein Themenwechsel.
