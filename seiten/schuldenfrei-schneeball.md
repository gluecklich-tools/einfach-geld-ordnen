# Schuldenfrei mit der Schneeball-Methode
Die Schneeball-Methode ist ein einfacher, motivierender Weg, Schulden planbar abzubaün: Du zahlst zürst die kleinste Schuld komplett ab, dann rollst du die frei gewordene Rate zur nächsten Schuld weiter.
## So funktioniert es (kurz und klar)
1. Liste alle Schulden (Restbetrag, Zins, Mindestrate).
2. Zahle auf **alle** Schulden die Mindestzahlung.
3. Den Rest deines Monatsbudgets für Schulden zahlst du **zusätzlich** auf die kleinste Schuld.
4. Wenn eine Schuld weg ist, addierst du deren Rate zur nächsten Schuld.
## Was du hier bekommst
* Ein schneller Rechner, der dir den Ablauf strukturiert
* Ein Download-Hub (Freebie / Vollversion-Links, sobald du es verlinkst)
* Ein klarer Nächster-Schritt-Flow ohne Sackgassen
