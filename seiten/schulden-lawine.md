# Schulden Lawine

Kurz: Self-Serve, klar, umsetzbar. Keine Beratung.

## Quick Start

1) Alle Schulden erfassen (Rest, Rate, Zins).
2) Hoester Zins zuerst fokussieren.
3) Nach Abzahlung Rate weiterrollen.
